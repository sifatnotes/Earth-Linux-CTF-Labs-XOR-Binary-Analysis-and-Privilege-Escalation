## Categories

- **Earth CTF challenges:** Access controls, reset mechanisms, trigger files, and secure messaging.
- **Binary analysis:** Binary inspection, strings extraction, and static versus dynamic analysis.
- **Tracing tools:** `ltrace` and binary behavior investigation.

## Learning Path

1. Start with the Earth access and secure messaging challenges.
2. Explore XOR-themed labs to practice logical problem-solving.
3. Learn binary inspection using strings and tracing exercises.
4. Compare static and dynamic analysis concepts.
5. Study SUID permissions and root-access risks from a security perspective.

Follow the prerequisites listed on each lab page and adjust the order to your experience level.

## How to Use the Labs

1. Select a challenge from the index.
2. Read the original lab instructions and learning objectives.
3. Use an isolated, authorized practice environment.
4. Record your observations, tools, and findings.
5. Document relevant mitigations and lessons learned.
